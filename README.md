# LiDAR 장애물 회피 실험실

목적지가 벽 너머에 있을 때 로봇은 어느 쪽으로 돌아야 할까요? 이 시뮬레이터에서는 전체 지도로 우회 경로를 구하고 그 경로를 달린 기록을 모읍니다. 이어서 앞쪽 거리와 목적지 정보만 받는 모델을 학습시키고, 실제로 목적지에 얼마나 자주 도착하는지 비교합니다.

처음에는 **수집 → 처음이라면 · 사전 이론**을 열어 보세요. **5 해석**에서는 ‘지도와 센서 → 주행 기록과 모방학습 → 다섯 모델의 차이 → 실험 결과 읽기 → 실제 로봇으로 이어 보기’ 순서로 읽을 수 있습니다. 휠·위아래 방향키로 스크롤하거나 목차로 이동하고 각 장에서 관련 실습으로 이동합니다. 같은 본문은 [그림이 포함된 Markdown 가이드](docs/guide.md)로도 읽을 수 있습니다.

## 실험 방법

* **데이터 수집**을 시작하면 로봇이 A*로 계산한 경로를 따라갑니다. 주행 중에 라이다 거리, 목적지 정보, 그때의 속도와 회전 명령을 함께 기록합니다.
* **모방학습**에서는 관측 28개(라이다 거리 25개, 목적지 상대 방향의 sin·cos, 정규화 거리)를 바탕으로 기록된 행동을 예측합니다. 다섯 모델은 주행할 때마다 이 관측으로 다음 행동을 정합니다.
* **하드웨어 가속 (CUDA + Intel NPU)**:
  - **학습**: NVIDIA GPU가 있으면 자동으로 **CUDA**, 없으면 **CPU** 사용 (`[2 학습] → [학습 설정]` 탭에서 전환 가능)
  - **추론**: `[3 레이스]` 탭에서 **`PyTorch CPU` / `CUDA GPU` / `OV CPU` / `OV NPU` (Intel AI Boost)**를 선택해 실제 NPU 하드웨어에서 자율주행 추론 및 속도 비교 가능 (OpenVINO IR `.xml/.bin` 자동 내보내기 포함)

## 실습 순서

1. **수집** 탭에서 **데이터셋 자동 생성 시작 (실시간 주행)**을 누릅니다. 지도에서 초록색 경로와 노란 추종점을, 오른쪽에서 늘어나는 샘플 수를 확인합니다. **샘플 3,000개 일괄 생성**은 현재 데이터셋에 샘플을 한 번에 추가합니다. 직접 조종한 기록을 담으려면 **수동 주행 데이터 수집 시작**을 누릅니다.
2. **학습** 탭에서 회귀 또는 분류를 선택한 뒤 **5종 모델 일괄 학습**을 누릅니다. 비교표에서 현재 학습 중인 모델과 검증 성능을 확인합니다. 개별 모델을 선택해 따로 학습할 수 있고, **학습 설정**에서 장치·에포크·증강·클래스 균형을 조정합니다.
3. **레이스** 탭에서 먼저 **A · 기본 회피**를 선택한 뒤 **동시 레이스 시작**을 누릅니다. 완주 결과를 확인한 다음 **B · 복합 난코스**를 선택하고 레이스를 다시 시작해 모델별 우회 경로 차이를 비교해 보세요. (수집 탭에서도 두 고정 맵을 선택할 수 있습니다.) 기준선(`BASE`, 라이다 회피 기준선)은 지도 없이 학습 모델과 같은 라이다 25빔·목적지 정보만으로 목적지 인력과 장애물 척력을 합쳐 회피하는 간단한 규칙 기반 주행기입니다. 지도와 참가 모델 표에서 같은 색과 약칭을 따라가면 각 모델의 궤적과 도착 시간을 확인할 수 있습니다. **단일 주행**에서는 모델별 예측값을 볼 수 있습니다. **20맵 평가 실행**이 끝나면 도달률이 표시되고 결과가 `results/benchmark_20maps.csv`에 저장됩니다.
4. **시각화** 탭에서 그래프를 선택합니다. 3D PCA 그래프는 드래그로 회전하며, 모델별 그래프에서는 분석 모델을 선택할 수 있습니다. **현재 그래프 PNG 저장** 또는 **전체 6종 PNG 저장**을 누르면 `results/plots/`에 160 DPI 이미지가 생성됩니다.

5. **해석** 탭에서 검증 정확도 또는 MAE와 실제 도착·충돌·시간 초과 횟수를 함께 읽습니다. 최근 평가가 있으면 평가 당시 수치를 사용하고, 새로 앱을 열면 마지막으로 저장된 평가 CSV에 기록된 과제와 결과를 표시합니다.

숫자 키 `1`–`5`로 탭을 전환합니다. 수집 화면에서 `W/A/S/D` 또는 방향키로 조종하고 `Space`로 수동 주행 데이터 수집을 시작하거나 중지합니다. 레이스 화면에서는 `Space`로 주행을 시작하거나 중지합니다. 지도에서 좌클릭은 출발 위치, 우클릭은 목적지를 옮깁니다. `N`은 새 랜덤 맵을 만들고 `R`은 출발 위치로 돌아갑니다.

행동이 다음 관측을 바꾸는 모방학습의 특성에 관한 배경 문헌은 Ross 등(2011)의 연구에서 확인할 수 있습니다. [A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning](https://proceedings.mlr.press/v15/ross11a.html)
